# Vanishing Point Comparison
*A comparison of two methods for the finding of vanishing points in building interior images.*

## Info
Makes use of a dataset [NYU-VP](https://github.com/fkluger/nyu_vp) that labels indoor images from [NYU Depth](https://github.com/fkluger/nyu_vp) with vanishing point indicating lines.
Originally posted on [Kaggle](https://www.kaggle.com/code/bhgreenf/vp-detector/).
CSCI-B 475 Fall 2023, in partnership with Pete J. Irwin.
